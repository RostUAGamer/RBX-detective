# 🔍 RBX Detective

Сучасна десктопна програма на Python та **CustomTkinter** для отримання повної інформації та аналітики про будь-якого гравця Roblox.

## ⚡ Можливості

- **👤 Повне досьє профілю**:
  - `User ID`, системний `Username` та `Display Name`
  - Галочка офіційної верифікації (`Verified Badge`)
  - Статус блокування акаунта (`Активний` / `Забанений`)
  - Точна дата реєстрації та вік акаунта (роки + дні)
  - Опис профілю (Bio / About)
- **🟢 Статус у реальному часі (Presence)**:
  - Відображає, чи користувач офлайн, на сайті, у грі або в Roblox Studio
- **🖼️ Завантаження аватара**:
  - Отримує та відображає актуальний аватар гравця
- **📊 Соціальна статистика**:
  - Кількість друзів, підписників та відстежуваних
- **👥 Групи та посади**:
  - Список публічних груп, назва ролі, числовий ранг та кількість учасників у групі
- **📜 Історія минулих нікнеймів**:
  - Перелік усіх старих імен, які використовував гравець
- **🏅 Офіційні бейджі Roblox**:
  - Список рідкісних нагород (Homestead, Veteran, Friendship, Administrator тощо)

## 🚀 Встановлення та запуск

1. **Клонувати репозиторій**:
   ```bash
   git clone https://github.com/RostUAGamer/RBX-detective.git
   cd RBX-detective
   ```

2. **Встановити залежності**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Запустити програму**:
   ```bash
   python main.py
   ```
