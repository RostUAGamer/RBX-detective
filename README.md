# 🔍 RBX Detective

Сучасна десктопна програма на Python та **CustomTkinter** для отримання повної інформації, аналітики, ігрових досягнень та швидкого приєднання до гри будь-якого гравця Roblox.

## ⚡ Можливості

- **🎮 Приєднання до гри (Join Game)**:
  - Якщо гравець у цей момент грає в гру і його налаштування приватності дозволяють стеження — стає активною кнопка **«Приєднатися до гри»**. Вона запускає клієнт Roblox одразу на сервер гравця через deep-link або відкриває гру.
- **🏆 Досягнення з різних ігор (Game Badges)**:
  - Окрема вкладка для перегляду нагород, здобутих користувачем у різних іграх Roblox.
  - Підтримка власного `.ROBLOSECURITY` cookie (через кнопку ⚙️) для розблокування Badges API від Roblox.
- **👤 Досьє профілю**:
  - `User ID`, системний `Username` та `Display Name`
  - Галочка офіційної верифікації (`Verified Badge`)
  - Статус блокування акаунта (`Активний` / `Забанений`)
  - Точна дата реєстрації та вік акаунта (роки + дні)
  - Опис профілю (Bio / About)
- **🟢 Статус у реальному часі (Presence)**:
  - Офлайн, онлайн на сайті, у грі або в Roblox Studio
- **🖼️ Аватар гравця**:
  - Завантаження та показ фото аватара високої роздільної здатності
- **📊 Соціальна статистика**:
  - Кількість друзів, підписників та відстежуваних
- **👥 Групи та посади**:
  - Список груп, ранги, ролі та кількість учасників
- **📜 Історія минулих нікнеймів**:
  - Перелік усіх попередніх імен гравця
- **🏅 Офіційні бейджі Roblox**:
  - Рідкісні нагороди платформи (Homestead, Veteran, Administrator тощо)

## 🚀 Встановлення та запуск

1. **Клонувати репозиторій**:
   ```bash
   git clone https://github.com/RostUAGamer/RBX-detective.git
   cd RBX-detective
   ```

2. **Встановити залежності**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Запустити програму**:
   ```bash
   python main.py
   ```
